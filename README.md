# Bike_Sales_Analysis
Analysis project exploring customer demographics and bike purchasing trends

## Project Overview
This project explores customer demographics and bike purchasing trends using Microsoft Excel. The goal was to understand how income, gender, age, and commute distance relate to bike purchasing decisions.

## Dataset
The dataset was obtained from Alex The Analyst's GitHub repository and includes customer information such as:

- Gender, age, and marital status
- Income and education
- Occupation and number of children
- Homeownership and number of cars
- Commute distance
- Bike purchasing status

## Tools Used
**Microsoft Excel:** Data cleaning, IF formulas, PivotTables, and dashboard visualization.

## Data Cleaning
- Replaced gender abbreviations (M/F) with Male/Female.
- Formatted income values as currency.
- Used an IF formula to categorize customers into Adolescent, Middle Age, and Old age brackets.
- Standardized commute distance labels, including distances greater than 10 miles.
- Removed duplicate records.

## Analysis and Key Findings
**1. Average Income by Gender**

Male customers had higher average incomes than female customers in the dataset.

**2. Bike Purchases by Age Bracket**

Middle-aged customers purchased more bikes than customers in the adolescent and older age brackets.

**3. Commute Distance and Bike Purchases**

Compared bike purchasing patterns across commute distances to explore whether shorter or longer commutes were associated with purchasing a bike.

## Dashboard
Created an interactive-style Excel dashboard featuring three visualizations:

- Average Income by Gender
- Customer Age Brackets
- Customer Commute Distance

## Conclusion
This project helped me develop my ability to clean, organize, analyze, and visualize data in Excel.

One of my biggest takeaways was learning how analyzing different variables can reveal different patterns within the same dataset. By examining multiple customer characteristics, I gained a better understanding of bike purchasing trends and how to communicate findings through visualizations.
